## 2. 已修的缺陷

### A. 柱状图有负值时柱子画到画布外（**最严重，页面级破相**）

`charts.js:622-624` 给 `gs_bar` / `stacked_dual` / `bars_labeled` **写死** `y0 = 0`，
只按最大值定上界；SVG 又没有 clip-path。序列里出现负值时柱子会一路画出绘图区。

- `miax` Ex13「股票 capture（每 100 股，可为负）」：最小值 −0.028，上界 0.0073 ⇒
  越界 **3.8 个图高**，一片浅蓝色柱盖住了下面 Exhibit 15 与 Exhibit 17 的图与正文。
- `asx` Ex20「当月退市实体数（负值）」：整段全负（−40 … −4），`y1 = max × 1.22 = −4.88`
  落在最大值**下方**，上下界颠倒，整张图没有一根柱画得对。

**修法**（`build/axisfmt.py::_neg_bar_guard`）：在生成端把 `yfloor = min × 1.22` 钉住；
整段全负时再把 `ycap = 0`，让柱子从零线往下挂。给的下界比最小值低 22%，不会有任何一根柱
真的被截，所以图上不出现断口符号。引擎一行没动。

### B. 轴刻度印错：2.5 步长被四舍五入成整数 / 相邻网格线同一个数字

`ticks()` 的步长候选是 `[1, 2, 2.5, 5, 10] × 10^k`，而 `plainAxis(step)` 按
`-floor(log10(step))` 定小数位 —— step = 2.5 时得 0 位，于是 2.5 / 7.5 / 12.5 / 17.5
被印成 **3 / 8 / 13 / 18**（轴上「3」和「5」的间距与「5」和「8」一样宽）。
右轴默认 `pct0` 同理：y/y 量程窄时整列印成「−1% −1% 0% 1% 1% 2% 2%」。

实测中招 **60+ 张图**，最离谱的三个：

| 页 | exhibit | 修前 | 修后 |
|---|---|---|---|
| `sgx` | Ex24 月末上市证券只数 | `-3%│-3%│-3%│-3%│-2%│-2%│-2%│-2%│-1%` | `-3.25%│-3.00%│-2.75%│…` |
| `tmx` | Ex20 BAX 未平仓 | `-101%│-101%│-101%│-100%│-100%│…` | 该图的次轴已按 D 撤掉 |
| `ndaq` | Ex10 市占率（本页脊梁） | `0│3│5│8│10│13│15│18│20` | `0.0│2.5│5.0│7.5│…` |

**修法**（`build/axisfmt.py`）：把引擎的 `ticks()` / `alignZero()` / 各 kind 的量程分支在
Python 侧复算一遍，算出最终刻度序列，取「既不出现重复标签、又不四舍五入到错值」的最小
小数位，只在不够时把 `yfmt` / `yoy.yfmt` 升一档（`f0→f1`、`pct0→pct1`…）。
**整数步长的图一位不加**，已验收上线的版式不变。`build/cboe.py:507` 早就手工绕过同一个坑，
这次把它抽成公共模块，`single.py` 与四张 `exchanges_*.py` 共用。

### C. 同比整条算不出来时仍画出一条假的次轴 / 一条图例里有图上没有的均线

`rhsOf()` 只看 `ex.yoy` 在不在就判双轴。`yoy.values` 全是 null 时
`Math.max.apply(null, [])` = −Infinity，量程退化成 `[0, 1]`，右边印出一列
「0% 0% 0% 1% 1% 1%」的刻度，而那条金线一个点都没画。

- `enx` Ex30 电力衍生品名义未平仓（2026-03 起，窗口内只有 4 个月）
- `sgx` Ex17 加密永续期货（2025-11 起，8 个月）

第一版修法是「同比整条算不出来就不给 `yoy`」，但 `gs_bar` 少了 `yoy` 会回落到
「柱 + 12 个月均线」，均线取 `ex.avg12`；两个都没有时引擎画的是 `Y(undefined)` = NaN
（虚线根本不出现），**图例却照旧列着「Prior 12mo Avg.」** —— 一条图例里有、图上没有的线。
仓里的 `build/verify_pages.py` 有专门一条规则拦它，第一版直接被拦下（2 个 ERROR）。

**最终修法**（`build/single.py::bar_ex`）：序列短到既没有同比、也没有 12 个月均线时，
整张图换成 `bars_labeled`（深蓝柱 + 每柱数值、单轴、`legendHTML` 对这个 kind 不产出任何
条目），不承诺任何画不出来的东西。与本页其余 `gs_bar`（浅蓝柱 + 金色同比）**不同色是刻意的**，
图注里写明了。`verify_pages.py` 现在 0 ERROR 0 WARN。

### D. 口径断点标到不相干的图上（**图注与图不符**）

`Page.breaks_for()` 里断点不写 `col` 就对本页所有列放行。实测：

- `asx`：「保证金口径换代：表内现金保证金 → 保证金总额」出现在 **31 张图里的 27 张** ——
  现货成交额、退市实体数、OTC 清算名义额、CHESS 托管、上市融资全被标了一条跟保证金
  毫无关系的红线，图注还跟着写「红色竖虚线 = 口径断点（保证金口径换代…）」。
- `miax`：「MIAX Sapphire 上线（变 4 所）」出现在 **19 张里的 16 张** —— Pearl 股票
  ADV/份额/capture、MIAX Futures 的农产品与金融期货、期货交易日数全被标上；
  开一家**期权**所既不改股票口径也不改期货口径。

**修法**：在 `build/specs/asx.py` 与 `build/specs/miax.py` 里把每条断点绑到它真正涉及的列
（一条断点涉及多列就按列各登记一份）。修后 asx 命中 1 张（Ex30 保证金新口径）、
miax 命中 4 张（Ex2/4/7/8，全是期权口径的图）。页面「口径与方法说明」里那句
「红色竖虚线画在 Exhibit …」是从实际命中生成的，会自动跟着改。

### E. 同一条断点在同一张图上画 2–4 遍

D 的修法要求「一条断点按列各登记一份」，而 `enx` 的断点表（`series/enx_breaks.csv`）本来
就是按列登记的。一张图同时画了其中好几列时，`breaks_for()` 会把同一个月份 push 好几次 ——
**同一格上重合画 2–4 条红虚线、并排 2–4 份同样的竖排标签**，图注里那句「口径断点（…）」
也重复写好几遍。实测 `enx` Ex6（4 条）、Ex9 / Ex10 / Ex16 / Ex18（各 2 条）。

**修法**（`build/single.py::breaks_for`）：按 `(索引, 标签)` 去重。

### H. 次轴末点读数正好落在某条刻度上时把刻度盖掉

`charts.js` 末尾的 `dropClashingTicks` 是**故意**这么做的（注释：「读数是真实数据、
刻度只是标尺，冲突时让刻度让位」），所以右轴上偶尔缺一格刻度是设计而不是 bug ——
例如 `ice` Ex12 的右轴少了 `-20%` 那一格，因为金线末点读数就是 −20.0%。
§4 的刻度检查器会把这种情况报成「不等距」，判定时要按「剩下的标签是不是等差子列」看，
本轮 71 条告警**全部**属于这一类，无一是真错。

### 6.1 缺陷 F'（横截面页版）：45° 的 x 类别标签向下伸出画布，压在 Note 正文上

**几何**（`charts.js:521-522` + `730-736`）：x 标签默认 `rot = n > 20 ? 90 : 45`，
底部只留 `XB = 36px`。45° + `anchor='end'` 的文字是**从锚点往左下方铺开**的 ——
锚点在 `M.t + ph + 9`，文字向下伸 `0.707 × 文字宽`。于是

```
0.707 × w ≤ 36 − 9   ⇒   w ≤ 38px   （8.2px 字号下约 8.5 个拉丁字符 / 4.6 个汉字）
```

超过就画到 SVG 外面。实测：`NYSE Group` 49px → 越界 8px；`MIAX Pearl` 44px → 4px；
`Deutsche Börse` 61px → 16px（这一张在 1:1 截图上直接横穿 Note 第一行，字压字）。

**为什么不用任务书给的两个方案**：那两个方案（(a) 纵轴按百万计缩短刻度位数、
(b) 改 `lines` + `markers` 去掉左端标签）都是冲着「左端标签 + `tickW`」这个（误判的）根因去的。
真根因是**下**边界，与轴刻度位数、与 `lines_endlabels` 全无关系 —— 两个方案都改不掉它，
而且方案 (a) 还会连带改掉核对表的量级，代价大得多。

**实际修法：类别轴一律水平排（`xrot: 0`）。**

| 为什么是它 | |
|---|---|
| 几何上不可能再越界 | `rot === 0` 时引擎改用 `XB = 22px`、`anchor='middle'`、不加 `transform`，文字只向下伸约 2px；`ph` 不变（`ph = height − M.t`，与 `XB` 无关），绘图区一个像素都没少 |
| 不用再砍名字 | 上一轮为这个问题给 `Member` 加了 `short=`，把 `NYSE Group (ICE)` 砍成 `NYSE Group` 还是不够短；水平排之后 `Deutsche Börse` 全名照写 |
| 与姊妹页统一 | `exchanges-eu` / `exchanges-apac` 的同类图**本来就是 `xrot: 0`**，所以这不是新增一种版式，是把跑偏的两页收回来 |
| 代价可算 | 约束从「文字宽 ≤ 38px」换成「文字宽 < 自己那一格 band」。逐图核过：最挤的是 `exchanges12` Ex4（12 格、通栏、band ≈ 92px，最宽 `Deutsche Börse` 61px，与邻居净间距 ≥ 38px）；半栏 5–6 格的 band 是 84–100px。**修后 OVERLAP 检查器 0 命中** |
